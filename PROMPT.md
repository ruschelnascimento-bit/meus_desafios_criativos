# Atue como um especialista em N8N

Crie uma automação para ler logs de equipamentos de rede e informar caso algum apresente um log de erro, alerta, atenção falha ou algo similar que necessite atenção para correção.

## Público:
Setor de Tecnologia

## Ferramentas envolvidas:
Agente de IA, Telegram

## Fluxo:
Em horário específico acessa o equipamento para coleta das informações, se detectado um erro ou algum tipo de anomalia, envia o detalhamento ao grupo pelo Telegram.

## Regras:
Ignora outros registros a menos que os mesmos sejam excessivos, podendo haver alto consumo de processamento e memória.

## Instruções finais:
Explique quais nós do N8N devem ser utilizados e a lógica de funcionamento do workflow.
